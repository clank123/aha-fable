# Aha Fable Calibration Example

## Input

Recent notes show the user is designing long-term systems, but collaborators do not act because they do not feel an immediate need.

## Output

**判断**

The gap is not that the long-term plan is wrong. The gap is that the plan has not attached itself to the other person's present pain.

**寓言**

山北有个村子，每年夏天都缺水。

有个年轻的匠人从城里回来，带着一卷很大的图纸。他告诉村民，只要大家一起花三个月，在山腰修一条长渠，雨季的水就能被引进村口的大池子。以后再遇到旱天，大家就不用每天走两里山路去挑水。

他说得很清楚。

哪一段该挖，哪一段该铺石，哪一段要留闸口，哪一段能防洪。他甚至算出了十年以后每户人家能少走多少路，少磨坏多少双鞋，少耽误多少农活。

村民们听完都点头。

第二天，没人来。

匠人很生气。

他觉得这些人短视，只看眼前，不懂长远。他又开了一次会，把图纸画得更大，把未来讲得更明白。

第三天，还是没人来。

傍晚，他坐在井边，看见一个女人背着水桶回来。桶里只剩半桶水，另外半桶洒在山坡上。她的手被桶绳勒出血，身后还有两个孩子在哭。

匠人忍不住说：“你们为什么不肯修渠？修好了以后，就不用这样辛苦了。”

女人看了他一眼，说：

“我知道渠很好。但我今晚要烧饭，孩子要喝水，院子里的羊也要水。你说的池子在三个月以后，我手里的桶在现在。”

匠人愣住了。

第二天，他没有再拿图纸。

他跟着村民走了一趟山路。他发现真正折磨他们的，不是“不理解未来”，而是每天有三个眼前的麻烦：

桶绳勒手。

山坡最陡的地方容易洒水。

井口排队时，前面的人多打一桶，后面的人就得等很久。

于是匠人先做了三件小事。

他给每个水桶加了一截软木把手。

他在最陡的山坡旁铺了十几块防滑石。

他在井边做了一个小木槽，谁多打出来的水，会顺着木槽流进旁边的小缸，后面的人可以直接取。

这三件事没有改变整个村子的命运。

但第三天，村民开始主动找他。

有人说：“山坡那里能不能再铺长一点？”

有人说：“那个小缸如果再大一点，早上会不会省更多时间？”

有人说：“如果水能从井边流到村口，那是不是就不用每次都爬上来了？”

匠人这才重新打开图纸。

只是这一次，他没有先讲十年以后。

他指着刚做好的小木槽说：

“我们把这个东西，往山下延长一点。”

村民们沉默了一会儿。

然后有人拿起了锄头。

三个月后，长渠真的修成了。

但它不是从那张宏伟图纸开始的。

它是从一个不勒手的桶、一段不滑的坡、和一条让人当天就少等一会儿的小木槽开始的。

**揭露**

这个概念叫：长期系统必须寄生在当下需求上。

长渠对应长期系统和正确规划；水桶、陡坡、排队对应执行者今天真实承受的摩擦。村民不是看不见未来，而是被现在拽住。能落地的长期方案，通常先伪装成一个今天就有用的小东西。

**行动**

不要先要求别人理解长期价值。先把长期价值切成一个当天就能减痛、增利、少背锅的小动作。

**灵魂反问**

如果你不允许自己再解释长期价值，你能不能把这件事改造成对方今天就会主动伸手来拿的东西？
