# Aha Fable Repository Shim

This repository root contains product docs, content drafts, and the runtime skill.

For normal use, follow the runtime skill instructions in:

`skill/aha-fable/SKILL.md`

If examples are needed, read:

`skill/aha-fable/references/example-output.md`

Do not treat this shim as the full operating prompt. It exists so installing from the repository root still gives the agent a valid entry point. The recommended install path remains:

`https://github.com/clank123/aha-fable/tree/main/skill/aha-fable`
