# Aha Fable（啊哈寓言）

把抽象概念、近期笔记、会议记录和 AI 对话洞察，转成一个让人读到最后才突然明白的寓言故事。

它不是总结工具，也不是鸡汤生成器。它的目标是让一个高阶判断通过故事被看见，再用一句反问逼近行动。

## 30 秒演示

看这个脱敏示例：[30-Second Demo](examples/30-second-demo.md)。

它展示了 Aha Fable 的核心差异：不是先给一个概念再写故事，而是先从一段真实困惑里诊断出隐藏原则，再把它转成寓言、行动和反问。

## 来源与改造

Aha Fable 不是从零发明的。

它受网上流传的 Anthropic / Amanda Askell 相关“用寓言解释概念”的提示词启发：先用一个间接故事承载概念，最后再揭示概念名称。

这个仓库里的版本是二次改造：

- 原版更像 **概念教学 prompt**：用户先给出一个概念，再让 AI 用寓言解释。
- Aha Fable 更像 **经验诊断与行动转译 skill**：它可以先从 flomo、Get Notes、复盘、会议材料或经用户授权的 AI 对话记录里，诊断出隐藏原则，再写成寓言。
- 原版重点是“理解概念”；Aha Fable 额外要求输出“行动”和“灵魂反问”。

## 适合谁

- 经常写 flomo、日记、复盘、Get Notes、会议纪要的人。
- 想从最近 AI 对话中提取真实洞察的人。
- 想从碎片里看见更高层原则的人。
- 想把复杂方法论讲给团队、合伙人、读者或自己的人。
- 做内容、咨询、经营、组织管理、AI 工作流复盘的人。

## 它解决什么问题

很多人不是没有洞见，而是洞见太抽象：

- 自己懂，但讲给别人时变成解释负担。
- 写成文章时像说教。
- 给团队讲时，对方听懂了但不会行动。
- 学了一堆方法论，却没有形成一个能被记住的故事钩子。

Aha Fable 把一个概念变成四段输出：

1. **判断**：先指出这组材料背后的真正压力。
2. **寓言**：用间接故事承载概念，不提前讲破。
3. **揭露**：说出概念名，并对应故事里的关键情节。
4. **灵魂反问**：给出一个不能轻易绕开的行动问题。

## 快速使用

安装后，在对话中这样说：

```text
使用 aha-fable，读我最近这几条笔记，找一个第一性原理层的盲点。
请用寓言故事写出来，最后给我概念揭露和一个灵魂反问。
```

也可以在你明确授权后，让它分析最近 AI 对话里的洞察：

```text
使用 aha-fable，基于我授权提供的最近 AI 对话摘要，找出一个反复出现但我还没说透的原则。
请写成寓言，并给出概念揭露、行动建议和灵魂反问。
```

如果你没有本地笔记，也可以直接输入一个概念：

```text
使用 aha-fable，解释这个概念：
长期系统必须寄生在当下需求上。
写成一个故事，不要在故事里直接说出概念名。
```

## 隐私说明

这个仓库只包含 skill 运行规则和脱敏示例，不包含私人 flomo、Get Notes 原文、AI 对话原文、公司数据、门店数据、客户信息或会议原文。

真实使用时，Aha Fable 可以读取你授权提供的材料，包括笔记、会议记录或 AI 对话摘要；但公开示例应默认脱敏。未经用户明确批准，不应读取、导出或公开任何私人记录。
